Workshop: HTML Heading

ฝึกใช้แท็ก <h1> – <h6> และการปรับขนาดหัวข้อด้วย CSS

1. ความหมายของ Headings

  • H1 – หัวข้อใหญ่สุด
  • H2 – หัวข้อรอง
  • H3 – หัวข้อย่อย
  • H4 – รายละเอียดลึกขึ้น
  • H5 – ใช้น้อย
  • H6 – เล็กสุด

H1 ควรมีเพียง 1 อันต่อหน้า เพื่อ SEO และโครงสร้างเว็บ

2. ตัวอย่างการใช้ H1–H6

Code
                <h1>Welcome to My Website</h1>
                <h2>HTML Basics</h2>
                <h3>What is HTML?</h3>
                <h4>HTML Syntax</h4>
                <h5>Example Code</h5>
                <h6>Note: Case Sensitive</h6>

H1: Welcome to My Website

H2: HTML Basics

H3: What is HTML?

H4: HTML Syntax

H5: Example Code
H6: Note: Case Sensitive
