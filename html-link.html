                            <img src="photo/images.jpg">

🎯 จุดประสงค์การเรียนรู้

  1. อธิบายการใช้งานแท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่าง ๆ
  2. แทรกรูปภาพด้วยแท็ก <img> พร้อมกำหนดคุณสมบัติพื้นฐาน
  3. ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน

🏷 แท็กที่ใช้บ่อย

📋 ขั้นตอนการฝึก

  1. สร้างลิงก์
  2. เพิ่มรูปภาพ
  3. กำหนดขนาด
  4. ตกแต่งด้วย CSS
  5. ทดลองใช้งาน

📤 ส่งงาน

สร้างหน้า HTML ที่มีทั้งลิงก์และรูปภาพ

💡 เกร็ดความรู้

แท็ก a ใช้สร้างลิงก์ ส่วนแท็ก img ใช้แสดงรูปภาพ สามารถกำหนด width, height และ alt ได้ และใช้ CSS ช่วยตกแต่งให้เว็บไซต์ดูสวยงามมากขึ้น
